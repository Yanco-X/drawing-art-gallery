# Dashboard UI Phase 1 Spec

## Overview

This is phase 1 of 3 for the landing UI layout. Use the screenshot referenced below for how it should look.

## Requirements for phase 1

- Home route at /home
- Content area is a grid
- Each piece should be a square image card with a link to /piece/id
- Main home layout and any global styles
- Dark mode by default
- Top header bar with search and new item button (display only)
- No sidebar for now
- We won't use any library for now, we'll create our components with tailwind
